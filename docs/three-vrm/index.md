# Tutorial: three-vrm

three-vrm은 **VRM 3D 아바타**를 Three.js에서 사용할 수 있게 해주는 라이브러리입니다.
*인간형 3D 모델*의 뼈대 구조, 표정, 물리 효과, 애니메이션 등 아바타의 모든 기능을
**통합적으로 관리**하고 제어할 수 있게 해줍니다. 특히 일본 애니메이션 스타일의
*가상 캐릭터*를 웹에서 표현하는 데 최적화되어 있습니다.
